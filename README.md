🌟 What's This All About?

Ever wondered how to manage student marks without drowning in spreadsheets? 🤯

Well, here's the solution!

Student Marks Management System is a simple project designed to make storing, calculating, and tracking student academic performance easier.

Think of it as your digital marks notebook! 📝

🚀 Features
🎯 Feature	💡 Description
👨‍🎓 Student Details	Store student information
📊 Marks Management	Record subject-wise marks
🧮 Total Calculation	Calculate total marks
📈 Percentage	Calculate student percentage
🏆 Performance	Track academic performance
📋 Records	Keep student records organized
